# jankenpo-julia

## Instalação

Instale primeiro a linguagem, seguindo as instruções da página oficial de downloads.

## Execução

Depois de instalar, rode:

```
julia index.jl
```

Não sou programador dessa linguagem; talvez os comentários de documentação da função não sigam o padrão mais recomendado por aqui, mas dá para entender — documentei no estilo das linguagens que já uso.
